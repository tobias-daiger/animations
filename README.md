## Featured Visualizations

### Damped Pendulum (Modeling & Simulation)
A MATLAB-based simulation illustrating the decay behavior of a damped pendulum:
- Automatic peak detection and marking ($P_1, P_2, P_3, \dots$)[cite: 80, 117]
- Dynamic rendering of chord segment lines ($s_1', s_2', \dots$) between consecutive turning points[cite: 31, 117]
- Export options for high-framerate (60 FPS) MP4 videos optimized for presentation decks.
